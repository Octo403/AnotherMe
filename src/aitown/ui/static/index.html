首次使用

让课程资料开始工作

  1. 选择模型 API，填写自己的 Key 和型号，可先读取型号列表。
  2. 点击下方“测试并完成”，保存后即可按提问进行第二轮筛题。
  3. 打开“课程资料”，收集公开课程，或上传自己的 PDF / Word / MD。

API 方式无需安装 Codex、下载大模型或配置 Python。模型调用需要联网，并使用你自己的服务额度。个人资料回答模式单独设置。
