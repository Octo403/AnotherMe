# T12 合成演示与截图

所有示例都是虚构资料，截图来自实际本机页面。未打开真实微信 HTML、媒体、映射或个人库。此演示展示表达参考和有来源的功能，不作为本人相似度测评。

本页保留 2026-10-06 的合成演示记录。2026-10-07 按用户要求完成的真实微信演示，启动方式、来源和私有截图另见 `WECHAT_UI_DEMO.md`（仅本机研究记录，不随源码发布）。

## 复现

先安装 README 所列依赖。离线演示无需模型；完整演示需要已配置且运行的本机模型：

```powershell
.venv\Scripts\python.exe scripts/verify_ui.py --output data/evaluation/t12/my-demo --keep-server
# 无本机模型时加入 --skip-live，仅验证离线部分
# 在另一个终端渲染；需要已安装的 Chrome
.venv\Scripts\python.exe scripts/render_ui_demo.py data/evaluation/t12/my-demo/report.json
```

端口默认 8502，可用 `--port` 更改。每次演示选新的输出目录名，以便独立创建运行库；报告、执行正文和 PNG 保存于输出目录，SQLite、索引与浏览器缓存保存在被忽略的 `data/runtime/`。脚本通过真实 HTTP 接口操作，`--keep-server` 保留页面供查看；Ctrl+C 停止。渲染脚本使用独立无头 Chrome 配置，不控制用户浏览器会话。

## 展示顺序

1. 打开空会话，指出单个 AnotherMe、合成资料标记、模式与会话列表。
2. 离线计算 `9 * 18`，得到真实工具结果 162；切换另一会话，历史为空。
3. 问“我喜欢咖啡还是茶？”，展开显式自述来源；提交“不像我”批注，并具体纠正为“喜欢温水”。下一问使用新值，旧回复提示来源变化。
4. 关闭计算器后再次计算，显示执行失败；重新启用。导入虚构图书角 571 本书的 MD、实际检索后删除，旧引用不再展示。刷新索引，查看画像。
5. 关闭并重开 Agent/数据库连接，确认历史仍一致。问活动室容量，随后问“之前说的需要提前预约吗？”，从本会话用户话语解析活动室并取得提前两天的来源。
6. 切换真实本机模型，回应邀请；查询活动室 9 人，执行检索每人 18 元→计算 9 个人费用得到 162；自主选择记忆查询→对话整理，保留计划未完成的含义。
7. 问未有来源的个人月球经历，程序停止生成。演示脚本随后有意注入“999人、去过月球”的错误初稿，交给真实模型自省，修回来源中的 9 人；初稿和修正可在运行详情核对。这是明确标记的纠错实验，不伪装成随机自然错误。
