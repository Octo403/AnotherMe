# AnotherMe v0.1.0-preview.1 · Windows 便携体验版

下载附件 **AnotherMe-Portable-Windows-x64.zip**（708,478,157 字节，约 708 MB），完整解压后双击 **Start.bat**，即可在本机浏览器中体验。附件已包含 Python、应用依赖和 LibreOffice，无需安装 Python、Word、Docker 或 Codex CLI。GitHub 自动生成的 Source code ZIP / tar.gz 仅为源码，不是可双击启动的体验版。

首次引导可配置自己的模型 API 地址、Key 和型号，也可先用本地筛选。模型调用需自己的服务额度；包内不提供 API Key 或模型权重。

## 本版功能

- 输入课程名查找公开资料，后台收集、处理，查看进度并重试失败文件。
- 上传 PDF、DOC、DOCX、MD、TXT、HTML、ZIP，或补充公开网址与自建课程。
- MD 等文字资料展示标准题目；PDF / Word 保留原件与可定位的预览。
- 本地召回候选后，由配置的模型按本次问题进行第二轮筛选，保留出处与参考题追问。
- 独立模型设置，支持型号目录、手动填写、连接测试与 Windows DPAPI 加密保存 Key。
- 资料、处理任务、模型偏好和会话保存在解压目录的 `user-data/`，重启后可继续使用。

包内提供原创虚构试题用于体验；不含开发者个人资料、微信数据、现有课程原件或凭证。停止界面用 `Stop.bat`；备份和升级前请等待后台任务完成，再复制整个 `user-data/`。换电脑或 Windows 账户后需重新填写加密 Key。

## 验证与限制

真实 ZIP 在开发者 Windows 本机完成 14 项运行流程与 8 项 Edge 浏览器检查，包括中文空格目录、后台 MD / PDF / DOCX / DOC 处理、真实本地模型 API 第二轮筛选和重启持久化。详见 [公开验收摘要](https://github.com/Octo403/AnotherMe/blob/main/docs/verification/portable-20261009.json)。

目标系统为 Windows 10 / 11 x64，尚未完成干净虚拟机或其他系统版本验证。Word 转换的字体、公式、分页可能不同；扫描件、复杂公式与答案配对仍需审校。Word 题目未能定位时提供原文件入口，不保证每题都有截图。当前包未带 7-Zip；RAR / 7z 需另装工具。当前仅本地保存，未实现云同步或多人共享。
