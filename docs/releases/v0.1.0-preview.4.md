# AnotherMe v0.1.0-preview.4：微信资料同步试用

在“资料 → 个人资料”增加微信会话来源，接入 wechat-chat-export v1.3.5 的 `chat_full_parsed.json`。支持读取现有导出、调用另行配置的上游源码工具自动采集、定时同步、增量去重、清洗正文、预览复核与本地持久化。确认的本人记忆可以按会话范围检索，回复保留来源；课程题库与个人微信资料继续隔离。

上游按会话导出完整快照，没有消息推送接口。“定时读取文件”需要用户在上游重新导出；“定时采集”需要独立的工具 Python 环境和已登录的 Windows 微信，配置见 [微信同步说明](https://github.com/Octo403/AnotherMe/blob/main/docs/WECHAT_SYNC.md)。导出工具及依赖没有内置到此包。

只收录身份明确的纯文字，图片、语音、引用卡片及发送者不明的消息跳过。资料先清洗、再复核；本人记忆需单独确认。正文变化时，旧衍生记忆与事实失效。已忽略内容不会在重复同步时再次弹出。来源配置与清洗资料保存在原 `user-data/application/application.sqlite3`，不上传在线模型或 MinerU。

新用户下载完整 Windows x64 ZIP，完整解压后双击 `Start.bat`。preview.1 / preview.2 / preview.3 用户可下载小补丁：先停止资料处理与同步、正常关闭 AnotherMe，将补丁复制到原解压目录并覆盖同名文件，保留整个 `user-data`。补丁不含用户数据。

验证覆盖上游真实导出函数生成的虚构数据库快照、本机 HTTP 流程、Edge 桌面和 390px 界面、复核后本机 Qwen 回答及来源引用、重启保留、身份不明跳过、跨会话隔离、正文更新撤销旧事实、事务回滚和重复同步。没有实际读取真实微信聊天，不能据此保证所有微信版本可采集。当前不自动训练表达画像，清洗也不保证完整匿名化，请先选一个会话检查。
