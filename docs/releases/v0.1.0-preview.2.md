修复 Windows 便携版 Codex CLI 检测与课程目录报错信息，补充启动进度与诊断日志。

- 自动读取更新后的 Windows PATH，检查常见 CLI 安装目录；npm 入口使用绝对 Node 路径，支持平台程序回退。
- 设置中增加可选“Codex CLI 路径”，同时作用于型号目录与第二轮筛题，保存后重启仍有效。
- 区分找不到 CLI、安装不完整和未通过 ChatGPT 登录；提示具体处理方式。
- Start.bat 立即显示启动阶段；提供 Diagnose.bat、startup.log 与异常日志；浏览器启动等待不会阻塞网页服务。
- 课程目录错误显示具体 HTTP 状态、限流等待时间或网络提示；限流时停止立即重试；代理页或不完整目录不会覆盖已有资料。

首次使用请下载 **AnotherMe-Portable-Windows-x64.zip**，完整解压后双击 Start.bat。GitHub 自动生成的 Source code ZIP 不含运行环境。

已使用 preview.1 的用户只需下载 **AnotherMe-preview1-to-preview2-patch.zip**：先停止服务并等待后台处理结束，把补丁内文件复制到原解压目录，覆盖同名文件，再启动。补丁不包含 user-data，保留原目录即可。

本包没有代装 Codex 或提供登录账号。ChatGPT 模式需用户自行安装并登录 Windows CLI；API 和本地筛选模式仍可独立使用。验证范围与结果见仓库 docs/verification/portable-20261011-preview2.md。
