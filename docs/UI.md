## 启动与资料选择

在项目根目录执行，浏览器打开终端显示的本机地址：

```powershell
.venv\Scripts\aitown.exe --mode demo ui
# 已配置且启动本机模型时，也可直接使用真实模型
.venv\Scripts\aitown.exe --mode live ui
```

默认地址为 `http://127.0.0.1:8501`。可用 `--port 8503` 改端口。默认使用 `data/runtime/ui-synthetic/` 中的独立合成库，包含虚构活动资料、四组训练表达、偏好和一个尚未完成的计划；不会加载正式个人应用库、原微信导出、媒体或映射。表达画像描述的是合成角色，不代表本人相似度。合成库首次启动建立，此后保留纠正、删除和会话，不重置用户修改。

使用自己的已复核微信内容演示，先启动本机模型，再执行：

```powershell
.venv\Scripts\aitown.exe --mode live ui --data wechat --port 8501
```

`--data wechat` 将 `.env` 的已复核应用库复制到 `data/runtime/ui-wechat/`，保留个人来源、记忆、训练划分与表达样例，副本不带旧 CLI 会话或通用合成文档。界面标记“微信资料副本”，默认选择训练表达最多的范围。修改、反馈和新历史保存在副本中，正式库与正式画像不改。后续启动复用该副本；要重新取正式资料，使用新的 `--directory`。当前只包含已整理的小批微信资料，不是全部微信历史。

若要直接使用 `.env` 已配置的应用库，显式选择 `--data configured`，并指定已复核的资料范围；此模式的维护操作会写入所配置的业务库：

```powershell
.venv\Scripts\aitown.exe --mode demo ui --data configured --scope "已复核的会话代称"
```

将占位符替换为本地真实代称。`--directory` 在 configured 模式只选择 UI 元数据目录，业务库仍由 `.env` 决定。未指定范围的会话只查询知识资料；界面不会猜测来访者身份。每个新会话固定一个范围，切换范围应新建会话。原 CLI 会话也会列出，未知的原范围保持为空。

个人资料的真实模型开关只允许配置在 localhost、127.0.0.1 或 ::1 的本机服务。CLI 的既有 provider 配置不变。每次启动遵循本次命令的模式；默认离线，技能开关保留。若本机模型未配置，个人资料真实模型选项不可用。模型启动方式见 [LOCAL_MODEL.md](LOCAL_MODEL.md)。

2026-10-09 模型配置移入独立“设置 → 题库模型 / PDF 解析”，与课程收集及个人资料分开。题库可配置 ChatGPT 登录筛题、DeepSeek、OpenAI 或其他 OpenAI 兼容 API，读取型号列表并测试连接；可设置 JSON 格式、temperature、输出上限及图片。在线调用只处理题库与找题意图，不接收微信等个人资料。Key 可用 Windows 当前账户加密保存，接口不回传明文，未保存的 Key 重启后需重填。MinerU 使用单独 Token，可先试解析一份已授权公开原卷，样本不替换题库。详见 [题库模型说明](QUESTION_BANK.md#模型分工)。

## 使用

- 右上角“课程资料”进入独立资料库。可输入课程名筛选，点击“浏览全部课程”滚动选择完整目录；选择全部或先试3/10份，查看后台阶段、逐文件结果并打开本地原件。未收录课程需另行提供来源；也可直接发送“帮我准备线性代数知识库”。更新会重新解析，已有题目引用/审校/答案配对可能失效。
- MD/TXT 题目直接按正文、标题与小问排版，保留原文件入口和行号；PDF/Word 继续显示原图。Markdown 不执行源 HTML，LaTeX 目前保留源文。已用实际残差网络/科普讲座试题验证两道大题及其小问。
- MinerU可处理已授权的FDU-Sharing所有公开课程PDF及公开压缩包中的PDF，上传前重取公开副本；Word在本机转换。微信、个人文档与本地批注不上传。准备和解析仍可能部分完成；实际支持范围、失败记录和小样本结果见 [课程自助入口](QUESTION_BANK.md#页面自助新增课程2026-10-08)。
- 左侧新建或切换会话，聊天历史来自运行 SQLite。Enter 发送，Shift+Enter 换行；支持显式选择同意、拒绝、安慰等回应场景。
- 回复下展开“事实来源”，查看命中文本、已复核的清洗依据或显式用户自述/纠正及时间。表达画像和风格短示范放在另一栏，不能作为个人经历依据。没有原始 HTML 或媒体链接。
- “像我 / 不像我 / 事实不对”保存批注。批注不会自动改写画像或变成事实。“事实不对”内可选择当前范围的有效本人事实并填写新值；纠正与反馈同一事务提交，旧值保留为被替代记录，下一次查询读取新值。
- “个人资料”（资料库的个人资料页签）支持导入本地 TXT/MD 或粘贴正文，同名文件更新已有资料；保存后刷新索引。可删除独立导入文档，查看当前范围事实、已复核本人训练记忆和表达画像；技能开关位于“设置”。此导入属于个人知识资料，课程题库仍通过课程收集入口准备。来源关联的个人导出不通过此面板覆盖或删除。
- 模型/检索/技能失败显示明确结果。处理中报告图节点的实际阶段；初稿、自省、候选计划、错误、tokens 和轨迹放在“运行详情”。离线摘录标为离线结果，真实模式中的未生成/失败结果标为程序结果。
- 存在未完成检查点时显示“继续未完成的对话”。会话重启仍读取原历史。旧回答展示前重新检查来源；已更新或删除的依据不再显示旧正文、初稿或技能结果，提示重新提问。

反馈用于记录评价；自动学习新风格规则不在本次范围。具体纠正要求运行库与检索库为同一应用库。删除的是应用库中独立导入的文档，原本地文件不受影响；重新导入可恢复。历史显示最近 100 条，仍遵循既有 TTL。

## 服务结构与边界

`ui/server.py` 提供静态页面与 JSON 接口，`ui/service.py` 将 Agent 和 SQLite 操作交给同一工作线程，浏览器轮询真实任务阶段；同一时刻只执行一项工作。`ui.sqlite3` 保存会话标题/范围和技能开关，业务历史、反馈和纠正沿用应用库。`ui/demo.py` 创建有明确合成标签的独立数据，`ui/wechat.py` 通过 SQLite 只读备份创建已复核个人库的演示副本。

服务器只绑定 127.0.0.1。Host/Origin 检查用于防止其他网站通过本机端口发起资料修改；静态路径使用明确资源列表，正文用 DOM 文本节点显示，CSP 禁止外部脚本和嵌入。JSON 请求最多 2 MB，导入正文最多 50 万字符。不提供局域网多人服务或登录系统。没有新增通用审批或发布门槛。
