# 微信资料同步

原有个人资料来源是默认虚构演示库、手动 TXT/MD 知识文件、此前离线清洗并复核的微信资料副本。原有“微信资料”启动参数不会主动采集正在运行的微信。

新增入口为 **资料 → 个人资料 → 微信资料同步**，适配 [wechat-chat-export v1.3.5](https://github.com/zhuzhangxue/wechat-chat-export/releases/tag/v1.3.5)。上游按会话导出完整历史，没有新消息推送服务；AnotherMe 对快照定时读取、增量去重。自动采集需要 Windows 微信已登录，且符合上游支持的微信版本。

## 先用一个会话试用

1. 下载上游 Windows GUI 工具，登录自己的微信，导出一个有权处理的好友或群会话；不用导出媒体。
2. 在 AnotherMe 添加会话：填写本地别名、导出中的准确会话名称，选择“读取已导出的 JSON”，填入 `chat_full_parsed.json` 的完整路径。不要选 TXT/MD。
3. 点击“同步一次”，检查新增、变化、跳过的数量，再点击“复核新增资料”。每页最多 50 条；检查清洗正文、发送者和拟提取的记忆，勾选后确认。
4. 本人记忆需要单独勾选确认。只确认正文不会自动确认记忆；规则不能解释的句子保存在来源库，不会被猜成个人事实。
5. 点击“使用此资料范围”，再询问已确认的内容，例如“我喜欢喝什么？”；展开回复来源核对。不同会话与合成资料使用不同范围。

“定时读取文件”默认每 300 秒检查一次，但**不会让 GUI 工具自动重新导出微信**。自行在上游导出新快照后，才会同步到新消息。

## 自动采集（可选）

GUI exe 没有可调用的命令行接口。使用上游源码和独立 Python 环境：

```powershell
git clone --branch v1.3.5 --depth 1 https://github.com/zhuzhangxue/wechat-chat-export.git D:\Tools\wechat-chat-export
py -3.12 -m venv D:\Tools\wechat-chat-export\.venv
D:\Tools\wechat-chat-export\.venv\Scripts\python.exe -m pip install -r D:\Tools\wechat-chat-export\requirements.txt
```

在添加会话时选择“调用本机导出工具”，填写源码目录、这个环境的 `python.exe` 路径、可选的微信数据目录。先“同步一次”，再启用“定时采集”。每轮调用上游 `export_chat` 的文本导出，结束后等待设置的间隔；历史越多，每轮越慢，不保证秒级到达。当前仅适配 v1.3.5 的已核实格式。

便携包内的 Python 没有上游依赖，应使用独立环境。上游音视频依赖较大；AnotherMe 不调用媒体下载、语音识别或全局密钥清理功能。

停止及正常关闭会等待本轮导出结束，让上游清理解密临时目录；下次启动需手动继续同步。强制终止进程无法保证清理完成，按上游说明检查其临时缓存。

## 存储与资料边界

便携版保存在 `解压目录\user-data\application\application.sqlite3`。源码 UI 以页面显示的实际路径为准。库内包含清洗正文、来源配置、去重标识、已确认的记忆；来源配置中的准确会话名、发送者映射、路径仍属于本地隐私数据，不进入模型提示词。

临时导出位于同级 `wechat-sync-temp\run-*`，处理后删除 AnotherMe 自己创建的本轮目录。手动选择的原始导出不会删除。上游另有自己的解密临时目录及清理流程。先停止同步并正常关闭，再备份整个 `user-data`。

正文使用已有规则清洗手机号、密码、账号和已知联系人名；规则不保证完整匿名化，复核时应检查遗漏。身份不明的发送者不会被猜为本人。本次只收录身份明确的纯文字，不收录图片、语音、附件或引用卡片。

上游 JSON 的时间没有时区字段，目前按北京时间读取；其他时区导出的快照需先核对时间。

重复同步不重复入库，不重新弹出已忽略的相同消息。已复核正文变化时，旧的衍生记忆与事实失效，新正文重新等待复核。JSON 不完整、会话不一致或本人账号变化时，不合并该轮数据；不同账号应新建来源。快照中暂时缺少的历史消息不会自动删除。

“删除来源与资料”删除此来源的清洗正文、记忆和事实，保留用户原始导出。已有对话保留，但被删除来源的旧引用失效。个人微信资料不上传在线模型、MinerU 或 GitHub；个人回答沿用本机模型配置，课程题库使用独立存储。

当前完成采集、清洗、复核、持久化与已确认记忆查找，不自动训练表达画像，也不把所有聊天句子当作可确认事实。导出工具未内置到 AnotherMe 压缩包，需按以上两种方式之一准备。
