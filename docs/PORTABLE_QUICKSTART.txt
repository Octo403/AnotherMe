AnotherMe Windows 本地体验版

1. 将压缩包完整解压到可写目录，例如桌面或 D:\Apps。不要在压缩包内直接运行。
2. 双击 Start.bat，浏览器会自动打开。首次启动可能需要稍等；保留启动窗口。
3. 首次使用引导中选择“模型 API”，填入自己的服务地址、Key 和模型型号。
   可以读取型号列表；接口不提供列表时手动填写。点击“测试并完成”。
   不需要另装 Python、Docker、Codex CLI、Microsoft Word，也不需要下载大模型。
   API 调用需要联网及你自己的服务额度；没有 Key 可先用本地筛选。
4. 在“课程资料”中搜索公开课程并收集，或“补充课程资料”上传自己的文件、添加网址。
   示例资料文件夹中的 MD 为原创虚构试题，可用于首次导入。
5. 在聊天框选择 @ 题库，输入筛题要求。API 已配置时会进行意图理解和第二轮筛选。
6. 双击 Stop.bat 停止界面，或关闭启动窗口。再次双击 Start.bat 可继续使用。

资料与备份
- user-data\question_bank：课程原件、处理结果、题库 SQLite 数据库。
- user-data\application：会话、模型偏好、合成演示资料和应用数据库。
- user-data 在首次启动时创建；请不要删除。备份请在停止服务、后台收集结束后复制整个目录。
- 更新程序时先停止服务，将旧 user-data 复制到新解压目录；不要用空目录覆盖旧资料。
- 加密保存的 Key 绑定当前 Windows 账户；换电脑或换账户后需要重新填写。
- 原始发布包不含个人聊天记录、已收集的资料库或任何 Key。

文档支持
- PDF、DOC、DOCX、MD、TXT、网页，以及 ZIP；含 7-Zip 组件的构建还支持 RAR / 7z。
- DOC / DOCX 使用包内 LibreOffice 在本机转换，不需要 Microsoft Word。
- 转换后的字体、公式和分页可能与原件不同，应打开原件核对。
- 扫描 PDF、损坏、加密、旧式嵌入公式等内容可能需要人工核对；未识别内容会显示处理状态。
- 个人资料聊天默认使用合成资料和离线模式；题库 API 配置只作用于课程找题。
- ChatGPT 登录模式是已有用户的可选方式，另外需要其自己安装并登录 Codex CLI。
- 找不到已安装的 CLI：新开 Windows PowerShell 运行 where.exe codex，将返回路径填到设置的“Codex CLI 路径”，刷新型号并保存。
- 可运行 codex --version 和 codex login status 确认当前 Windows 账户的安装与登录；仅在 WSL 或插件中登录不能直接复用。

遇到问题
- 页面未自动打开：复制启动窗口中的 http://127.0.0.1:端口 到浏览器。
- 端口被占用时自动尝试其他端口；重复双击会打开已有服务。
- 启动窗口现在会立即显示阶段；卡住时查看 user-data\startup.log，启动异常另有 startup-error.log。
- 双击 Diagnose.bat 可单独检查依赖；不启动服务、不读取课程资料。
- 日志无法写入解压目录时会保存在 Windows 临时目录，实际路径显示在窗口中。
- 刷新课程目录失败会显示 HTTP 状态码：403 / 429 限流请按提示等待；407 请检查代理；404 请检查仓库或分支。
- 目录刷新失败不会删除原目录或已有资料；仍可查询已有题库、上传本地文件。添加网址仍需网络。
- 接口不支持 JSON Object 时，可在设置中切换“纯文本 JSON”并重新测试。
- 本体验包面向 Windows 10/11 x64，尚未提供 macOS、Linux 或 ARM 原生版本。

preview.1 升级补丁
- 先运行 Stop.bat，并等待后台资料处理结束。
- 将补丁 ZIP 内文件复制到原解压目录，覆盖同名文件；不要放进一个额外的子文件夹。
- 保留原 user-data，再双击 Start.bat；补丁不包含用户资料。
