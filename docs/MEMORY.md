# 可追溯个人记忆（T5）

2026-10-04 完成 T5.1—T5.7。规则抽取、复核、入库和知识文档检索全部在本地执行，未调用远程模型。现有聊天图尚未自动读取应用数据库；本模块为后续画像、检索与上下文提供材料和查询接口。

## 类型与归属

`memory/models.py` 定义事件、明确偏好、长期事实、临时计划、他人信息、推断、未知七类。每条包含主体、发生时间、记录时间、有效区间、会话范围、未知关系、数据划分、直接/推断依据、状态和逐条源消息。记录时间使用原始发言时间；批次导入时间仍由 `import_batches` 保存。发生日期无法确定时保留空值。

`memory/extract.py` 使用保守中文规则，不假称为通用语言模型抽取：

- 方向与说话人同时确定本人；对方“我喜欢”是对方信息。本人转述、引号、疑问、条件、玩笑和不确定表达保留未知，不强解“他”的身份。
- 优先识别独立明确自述；不从“对的”“我也是”或上下文不足的专业简称自动写入长期事实。显式负偏好保留否定；隐含本人计划仅适用于有限句式。
- 相对日期基于源消息的北京时间；未指定日期的“准备”“下周”不补造日期，较早记录也不按当前日期解释。
- 事件摘要最多选择六条已复核普通消息，优先明确陈述和事件两端，恢复原顺序，逐行保留说话人及原文。摘要不是整段事件的完整概述，部分摘录明确标注。全部 1,830 条源记录仍在 T4 归档中。
- 未复核文本、压缩正文及附件不参与语义抽取。多事件反复提到一个话题，只生成 `inferred/candidate`，不会确认爱好、性格或健康状况。

## 存储、时效与维护

应用 SQLite 从版本 1 迁移到版本 2，新增 `memories`、`memory_sources`；保留 T4 原表和历史数据。源关联有外键和事务。每条普通来源以批次/源消息 ID 标识；事件以批次/事件 ID 标识，重复导入不重复增加记录。

`MemoryStore.save(entries, reviews)` 将本地复核决定与候选解释字段对照，避免旧复核误用于改变后的解释；还核对原文、方向、说话人、时间和事件归属。候选默认不确认；推断及未知不能升级为确定事实。复核记录表示资料质量检查，不表示远程发送授权。

仅已复核的本人直接偏好/长期事实、且来源属于 train，才投影到 T4 `facts`。事件、计划、对方信息和推断保持独立。偏好按主体、会话、属性领域和划分处理；同一领域的新显式“现在/更喜欢”等更新关闭旧有效区间、保留旧来源。不同领域偏好不互相取代，不明确的关联不会合并。

`MemoryStore.query()` 默认查本人、直接依据、train、已确认且当前有效；支持 `subject/category/scope/as_of/split`。历史查询按来源可知时间与有效区间返回旧偏好。推断必须显式使用 `basis='inferred', include_candidates=True`；不确定日期的计划不会默认当成当前计划，明确日期的过期计划默认排除。历史记录仍可通过时间查询或 `include_expired=True` 查看。

`Repository.sources('memory', id)` 返回真实源消息。T4 删除/变更来源会清除整个依赖记忆、事实、托管文档和索引。数据库维护不会自动删除原微信导出或既有私有 JSON/MD 快照；删除资料后应重新导出或删除旧快照，独立 `KnowledgeBase` 读取文件时不能替数据库识别旧快照。

## 实际执行与复核

首批四个会话共 596 个归档事件，先检查已有可读复核事件，再逐项查看另外十二个事件的 41 条正文并更新来源复核记录，形成 **100 个可抽取事件**。这些事件的摘录与剩余已复核消息由 Codex 本地逐项检查，未冒充本人主观评估。其余事件因尚无复核普通正文保留归档，本次不扩展其语义解释。

复核发现并修正：最初六条摘录遗漏事件末尾计划；“感觉到了”误当完成动作；当天咨询发言时态不明确；显式负偏好和省略“我”的计划漏提；参加某个“计划”名称不能被误作未来计划。需要前文才能确定的简短专业回答保留原文，不强行形成事实。私有 `quality_review.json` 记录源 ID、问题和修正，`pilot_initial.jsonl`、`pilot_v1.jsonl`、`pilot_v2.jsonl` 保留运行阶段的候选记录；最终候选以 `batch.jsonl` 为准。

最终全批复跑得到 **114 条记忆**：101 条事件（含 100 个对话摘录和 1 个本人完成事件）、6 条计划、1 条偏好、2 条他人信息、3 条未知、1 条重复话题推断。110 条直接依据通过本地复核，未知 3 条、推断候选 1 条；事实投影只有 1 条，画像仍为 0。436 次证据字段比对一致，外键无错误；重复导入增加 0 条。

小批结构化候选的前一版 11 条中有 1 条时态误分类；修正后逐条查看 10 条直接陈述。这个小样本不代表全量抽取正确率，更不能据此估算召回率。保守规则会漏掉依赖上下文的事实，原文归档保留以便后续扩展。

## 命令与导出

以下路径均为私有本地资料，已在 `.gitignore` 排除：

```powershell
.venv\Scripts\python.exe -m aitown.memory extract --limit 100 --output data/private/t5/pilot.jsonl
.venv\Scripts\python.exe -m aitown.memory extract --output data/private/t5/batch.jsonl
.venv\Scripts\python.exe -m aitown.memory load data/private/t5/batch.jsonl --reviews data/private/t5/reviews.json
.venv\Scripts\python.exe -m aitown.memory query --category preference
.venv\Scripts\python.exe -m aitown.memory export data/private/t5/knowledge/personal_memory.md
```

`--limit` 限制有已复核普通正文的事件数；不把空白或压缩事件算成完成语义处理。删除来源后不能直接再载入包含旧证据的候选文件，应重新抽取、检查和导出。

私有 MD 导出了 **49 条记忆、241 个来源**，只包含已复核 train 事件及本人直接信息；独立他人条目、推断、未知、过期或日期不明的独立计划不导出。对话事件仍可能含他人原话，逐行说话人标签必须随引用保留，不能把对话摘录解释为本人全部经历。dev/test/unassigned 不进入默认知识文档。

已实际通过 `KnowledgeBase` 的 TXT/MD 导入及 FAISS 查询，三个查询均命中，最高相似度分别约 0.197、0.060、0.105。此次含大量来源元数据的短查询使用显式 `threshold=0.03`，没有修改默认 0.15，也未把这个结果视作语义检索或精排验证。文档切片与来源联动继续由 T7 完善。

`data/knowledge/memory_demo.md` 是完全合成的教学素材；真实私聊 MD 不用于提交或默认聊天。61 项测试通过，覆盖归属、转述、玩笑、生日、否定、相对日期、历史偏好、推断隔离、留出过滤、迁移、重复导入、失败回滚、来源删除和实际 TXT/MD 导入。
